# P0 修复实施计划

> **For agentic workers:** 用 superpowers:executing-plans 逐任务执行本计划。步骤用 checkbox 跟踪。

**Goal:** 修 BUG.md 两项 P0——跨序列状态泄漏 + 评估链路（evaluator 空壳 / GT 恒空 / history 错位）

**Architecture:** 序列边界加 reset 钩子清三处状态；GT 从 `gt.default/gt_radar_1200/1201.bin`（AUTOSIL 稠密标注，28B 记录布局已实证）加载；evaluator 实装贪心最近邻配对 + CLEAR-MOT 基础指标。

**Tech Stack:** 既有 tracker 包（numpy/ctypes dataclass 体系），无新依赖

## Global Constraints

- spec: `tracker/doc/design/spec/2026-08-25-p0-fix-design.md`
- GT 记录 dtype（28B，已与 metadata 对拍实证）：`[id u2|x i2|y i2|z i2|vx i2|vy i2|heading i2|width u2|length u2|height u2|type u1|is_key u1|birth i2|dead i2|tail u2]`，标度 ×0.01；帧归属按 1200 头 `gtt_num` 累计
- GT 类名词典：1=轿车→Car 2=行人→Pedestrian 4=二轮车→Cyclist 5=卡车 7=静态障碍物（后两类无检测对应，排除评估）
- ghost 当普通 GT；匹配 = 贪心最近邻 + 中心欧氏距离 ≤ `match_dist`(默认 2.0m) + 类别约束（trk.type == GT 映射后 label）
- 指标：TP/FP/FN、MOTA、MOTP、IDSW、Frag，per-class + 总计；消费 METRICS.show 已实现项
- 测试风格：仿 `tracker/tests/`（脚本式、print ✓/✗、RESULT: PASS/FAIL、`sys.exit`），不引入 pytest 依赖
- 收尾统一一个 commit（项目规范），无中途 commit

### Task 3: evaluator 实装（P0-2c）

**Files:** Rewrite `tracker/evaluator.py`；Test `tracker/tests/test_evaluator.py`（新建）

**Interfaces:**
- Produces:
  - `Evaluator(cfg, class_names=None)`；`self.gt2label`（GT type→检测 1-based label，类名对齐 `class_names`，无对应不入表）
  - `match_frame(gts, trks) -> (matched[(gt,trk,dist)], unmatched_trks, unmatched_gts)`——纯函数可单测；类别过滤在内部（GT 不在 gt2label 直接进 unmatched 不计 FN——**注意**：排除类需完全剔除，不进 unmatched_gts）
  - `online(frame, trks) -> None` 逐帧累计；`on_seq_end(seq_name) -> None` 打印本序列累计并清零
  - `evaluate(history) -> dict`：history=[seq=[(gts, trks快照)]]，per-seq/per-class + 总计，打印 + `EVALUATE.report==1` 时落盘 `output/tracker_eval/report.txt`（追加）
  - IDSW 判定：`_gt_map[gt.id]` 保留上次配对 trk.id，复配且不同 → +1；Frag：`_gt_seen[gt.id]` 为 False（上帧漏配）且历史配对过 → +1；MOTA=1−(FN+FP+IDSW)/GT总数（除零守卫）；MOTP=Σdist/TP
  - METRICS.show 开关 gate 报告行（tp/fp/fn/ids/frag/mota/motp 七键，缺省视为 1）

- [ ] 3.1 写失败测试：①完美跟踪（单目标恒定 id）→ TP=n、FP=FN=IDSW=Frag=0、MOTA=1.0、MOTP=0；②中途换号 → IDSW=1；③断 1 帧再接回同号 → Frag=1、IDSW=0；④距离超门限 → FN+FP；⑤类别不符（Car 轨 vs 行人 GT）→ 不配对；⑥Truck GT → 完全不计；⑦evaluate 汇总 per-class 计数正确。构造假 GT/Trk 用 SimpleNamespace（GT 需 .id/.type/.x/.y，Trk 需 .id/.type/.x_m/.y_m）。运行确认 FAIL
