## 4. 阶段与验收（顺序执行，每段先对拍再进下一段）

- **S0 环境补齐**：onnx/onnxruntime + cmake + onnxruntime C++ 库。验收：import 通过、cmake 可用
- **S1 导出与基准**：export_weights / golden_dump / export_dpu_segment / parity_onnx。验收：N 帧 DPU 段 allclose ≤1e-5
- **S2 C++ 前段**：pillarize → vfe → attention → scatter，对拍 golden 的 spatial_features。验收：N 帧 allclose（FP32 相对误差 ≤1e-4 量级）
- **S3 C++ 后段**：decode_nms，输入用 golden 的 logits，对拍 golden 的最终框。验收：框数量/类/score 差 ≤1e-3，位置中心距 ≤1e-2 m
- **S4 全链仿真**：main.cpp 全链（本地数据 → ONNX Runtime → 框）vs PyTorch 端到端框。验收：同 S3 口径全过 → **达成目标**
- **S5 量化预产**（S4 后，非同结果门禁）：quantize（记录量化误差，为 INT8 掉点门禁留数据）→ compile_xmodel。验收：xmodel 产出 + 量化 sim 误差落盘

## 5. 关键口径（实现时冻结）

- 前段输入 = **N×6 点特征** `[x,y,z,dop_x_gnd,dop_y_gnd,rcs]`（与 FPGA 接口契约一致；doppler 对地补偿等特征工程在数据侧完成，不进 C++）
- DPU 段静态 shape bs=1：入 `[1,32,80,200]`，出 `[1,12,40,100]`；类别/通道布局/pc_range/voxel_size/out_size_factor 固化进 meta.json
- attention **true-N 动态**（勿 pad 3096）；NMS 用 CPU rotate IoU 复刻（非 CUDA kernel）；golden 帧数 50（spatial_features 较大，必要时 fp16 存）
