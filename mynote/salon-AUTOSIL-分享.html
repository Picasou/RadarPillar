01 · WHY

为什么做这个工具

公开数据集不够用

KITTI / nuScenes 的雷达数据质量不高；VoD 仅限高校科研、不能商用，设法获得后质量也不佳。

自采数据标注太贵

场地测试一圈下来几十万帧，逐帧画框的人工标注方式，人力完全扛不住。

下游不止训练

传统跟踪链路同样需要 golden case——统一「算法 / 系统 / 测试」的量化评估口径，闭环验证「改了有没有用、有没有跷跷板」。

两条核心设计思想，从一开始就定死
① 不依赖逐帧标注——借鉴 tracker 思想：相邻帧目标只轻微移动，标过的一帧就是下一帧的先验，人工只修正「变化量」，其余由引擎传播（唯一 ID + 关键帧）；  ② 不使用大模型——专业算法与代码介入（插值、运动补偿、统计），可解释、可追溯、可控。

03 · LOAD &CONFIG

3.1数据加载与配置驱动：换一款雷达，不改一行代码

自适应 struct——仅修改配置文件即可适配不同雷达；SP3 已实证，加载提速 18 倍
字段名 / 类型 / 字节偏移 / 缩放系数 / 单位全部外置 JSON，读盘自动物理换算；新硬件数据采回来当天就能看、能标、能转。
  • 四大格式家族通吃：自有 bin / KITTI / nuScenes / MSR / 自定义，数据树混排展示、双击即载，KITTI 类别自动归并统一 6 类；
  • 多传感器时间对齐：雷达 10Hz / 激光 20Hz / DGPS 17Hz 最近邻配帧，帧轴以点云为准——标注、播放、转换三端同一个帧轴；
  • 加载快不卡界面：向量化 + 多线程，提速实测 18 倍，点开 1 秒级出首帧；单源坏了只报那一个，其余照常。
  • 结构配置 JSON：SP3 实证——点云多 5 字段、单条 24→32 字节、目录换 S3FM，只落一套 JSON，加载 / 数据树 / 转换三条链路自动认识；
  • 帧率自适应：播放定时按数据真实帧时间戳中位数（10Hz = 100ms/帧），不写死帧率；
  • 注册表 + 参数全可配：新数据类型登记即全链路生效；动静态参数、标注阈值、转换切分、噪声幅度改配置即生效。
04 · VIEW

3.2可视化层：六种视图，一套交互心智

对地多普勒着色与雷达固件同源——屏幕上的分色，就是算法里的口径
按 |对地多普勒| / RCS / 信噪比 / 高度着色；颜色范围按物理量纲全局固定（多普勒 0~30 m/s、RCS ±25 dBsm），跨帧跨数据集可比。
  • 2D 鸟瞰图（标注主力画布）：真实尺寸旋转框、自动适配视野、单轴缩放看窄长场景；
  • 3D 立体视图：标注操作（拖拽 / 旋转 / 拉长短宽高）与 2D 完全镜像，学一次两边都会用；
  • 3DOCC 体素占用图：多帧点云累计成 3D 占用栅格——占用网络 / 自由空间算法的数据体检工具；
  • 多帧热力图 + 数据表 + 相机画面：密度 / 属性 / 逐字段明细 / 同帧影像，标注前摸底、标注后核对、训练后分析 bad case 用同一套视图。
真机截图：3D 立体视图（点云带 · HUD 实时统计 · 高度色带）
05 · WORKFLOW &CORE

3.3标注工作流与内核：一条轨迹的诞生

tracker 思想：上一帧永远是下一帧的先验——人工只修正「变化量」，引擎负责传播；内核侧，位置插值在世界系做 ego 补偿（投影 → PCHIP → 回投，角度走 sin/cos 分量），标出来的是目标的真实运动，不是自车运动的镜像。

06 · CLONE & STATIC

3.3克隆与静态化：从 80 分草稿开始标注

全量克隆 · 一键成稿

对跟踪得不错的检测轨迹：平滑去抖 → 差分速度（含 ego 补偿，静止自动归零）→ 自适应朝向 → 均值尺寸 → 众数类型，五步管线一步跑完。

产物每 10 帧留一个关键帧，后续拖拽修改只在 9 帧小窗内重算——动态轨迹不会被首末直线拉直。

静态目标 · 三板斧

路牌、护栏、停着的车：点一下「设为静态」，目标在世界坐标里钉死、速度自动归零，自车怎么开它都原地。

分段混合：粗对齐后拖某个锚点精修，修正量向前后两段自动传播。路侧环境标一次，相似场景复用，真值跨数据集复制粘贴。

配套生命周期管理：改 ID 合并两段轨迹 · ROI 关注区自动截断 · 长宽高改一次全帧同步 · 19 种操作一步撤销。

所见即所存
精修定型过的目标保存时跳过重新插值——屏幕上调好的轨迹，存下来再打开就是同一个样子；落盘走原子写，绝不留半个坏文件污染训练集。
07 · DATA TAGS

3.4数据标签：数据闭环的索引层

标签是闭环的索引——采集 → 标注 → 挖掘 → 训练，每个环节靠标签圈选数据
从数据目录名自动解析打标（红 = 无标签 / 黄 = 待确认 / 绿 = 已确认），按标签 + 日期筛选，实时显示「命中 N / 共 M」。
  • 五类标签体系（对标业界数据闭环实践）：场景 SCENE / 环境 ENV（天气·光照·时间） / 道路 ROAD / 参与者 PARTICIPANT / 行为事件 BEHAVIOR——自动打标 + 人工确认，同义标签统一口径防爆炸；
  • 目标质量属性：目标级质量标记（已确认 / 待确认 / 存疑）——鬼影、遮挡、低置信目标一眼可辨，低质目标不进训练圈选；
  • 质量门禁：未确认标签不进正式数据圈选——「先过审再上岗」；
  • 闭环联动：按标签圈选场景数据（如「雨天 + 夜间」鲁棒性子集）；标签覆盖率反哺采集——哪类场景存量少，下一轮就定向采哪类。
08 · TOOLKIT

3.4标注提效全家桶

  • 批量剔除四件套：FOV 扇形 / 条件组合 / 静态 / 闪烁鬼影——全部先出预览，拖帧滑块逐帧看谁会中标，确认才真删；
  • 轨迹曲线编辑器：把属性画成随帧曲线，像编辑音频波形一样修轨迹，一键平滑、一键全帧设同值，多 tab 并排对比；
  • 目录级统计：不加载就摸清存量——类别分布 / 属性直方图 / μσ 汇总，一键导出 HTML 报告；先看分布，再定标哪些。

10 · DATASET & AUDIT

3.6训练集定制 + 诚实对账

  • 切分四方式：顺序 / 时序轮转 / 随机 / 混合——时序切避免相邻帧泄漏进验证集；
  • 多帧点云叠加：历史帧按自车运动补偿对齐后合并，单帧稀疏的雷达点变密；
  • 噪声增强扩样：真值复制 1~5 份按类别可控扰动；同配置重跑逐字节一致，消融实验可比；
  • 跳帧 / 均匀抽稀 / 空帧降密度，全部界面上点选。

转完就是对的

按「原始数据组」对账：成功 X 组（Y 帧）——点云缺失的组整体判失败不硬转，拿着缺数据的数据集去训练这件事被堵死。

绝不静默失败

数值溢出显式报错、绝不静默落 0（假 0 值进训练比没数据更糟）；0 字节不算产出文件。历史上「丢 99.6% 还报成功」的事故之后，字节级双向对拍成为合入门禁。

13 · VALUE

这笔投入买到了什么

对标注

效率数量级提升：9 万+ 帧 / 20 人日，日均 4000+；质量下限由工具兜底——插值物理正确、所见即所存、落盘原子可靠，经验花在「标对」而非「别标坏」。

对训练

自采数据直通 KITTI / nuScenes / MC；切分防泄漏、叠加增密、增强可复现——实验变量控制权在算法工程师手里，不在写转换脚本的人手里；对账兜底，不带病训练。

对项目

场地数据 → 可信训练资产的生产线已跑通，模型训练与传统跟踪同时受益（golden case 量化标尺）；接新雷达成本从「排期改代码」降为「写一份 JSON」。

对团队

需求-测试双向追溯流程、踩坑定案知识库、「事故 → 定案 → 修复 → 守门」的工程闭环范式——可直接搬到下一个工具项目。
