# MSR 实验结论整理 2.0

> **数据**：model.xlsx 39 模型（41 次训练，2026-08-18 ~ 08-24）。2.0 版重组为「改动效应矩阵 + 部署导向选型 + 实验空缺」三段式，替代 1.0 叙事式总结  
> **口径**：mAP@R40 moderate EAA（IoU car=0.5, ped/cyc=0.25）；2D=BEV 4 类均值（含 Truck），3D 同；精度取 best.pth 对应 epoch；FLOPs=G@bs1 单帧；参数=M；表中 Δ 均相对该表注明的 baseline；判定分「精度 / 资源」两维独立给出  
> **纪律**：单次训练无种子重复，差距 <1 mAP 视为「相当」；ch2d 家族无 z/h，3D AP 结构性恒 0，跨家族仅以 2D 比较；Car/Truck 多数配置近饱和（97~99.9），Δ 解读以 Ped/Cyc 为主

## 三、实验空缺与补充建议（按优先级）

1. **ch3d_trunk × 宽 backbone（pp64/ppmix）**：backbone 实验全部固定 ch2d_trunk，centerhead3d_trunk 只跑过 PP32 窄版——2D 侧 +2.0~+2.7 的容量增益从未传导验证到 3D 侧，**3D 榜大概率未封顶**，且直接决定 tracker 选型上限。最优先补
2. **RepDwc 深宽度档对照**：radarNeXt 原版用 RepDwc[64,128,256]（我们最宽只到 64），其 92.10 来自宽 backbone / MDFEN / head 三者中谁未拆解——「RepDwc 无效」结论边界未覆盖其真实宽度
3. **中间宽度档**：pp64 参数 ×3.0（0.815M）与 ppmix 之间无对照，[48,48,48] / [32,48,64] 空缺，性价比曲线不完整
4. **种子重复**：trunk vs centerhead3d（+0.44/+0.35）、ppmix vs pp64（-0.64）均在 <1 mAP「相当」带内，关键对需 2~3 种子才可判；PN64 方差来源同待验证
5. **MDFEN 混杂拆解**：bs 8→4 与出口分辨率减半捆绑，需对齐 bs 的单变量重跑
6. **等预算通道位置对照**：[44,44,44] vs [32,64,64]（参数对齐），判「通道应放深层」是否成立

## 四、规律、口径教训与数据修正

**规律**
- 精度主线 = 小目标：换头 Ped +23.8、backbone 加宽 Ped +5.3，一切失败方向掉点也集中 Ped/Cyc——Car/Truck 早已饱和
- 有效杠杆排序：换 head > head 瘦身（trunk，零代价）> backbone 容量（pp64/ppmix）；无效杠杆：RepDwc、两级化、MDFEN、PN64、多头 PAtt、stride 变体
